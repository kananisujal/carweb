# 🚗 CarWeb – Car Website

## 📌 About the Project

CarWeb is a car website project developed as part of the Diploma in Computer Engineering program.

The main purpose of this project is to provide users with an attractive and user-friendly website related to cars. It presents car-related information through a simple and organized website interface.

## 🎯 Project Objectives

- To develop a user-friendly car website.
- To provide an attractive and responsive user interface.
- To organize car-related information.
- To improve practical web development skills.

## ✨ Features

- 🏠 Home Page
- 🚘 Car Information
- 🔍 Car Browsing
- 📱 User-Friendly Interface
- 🎨 Attractive Website Design
- 📞 Contact Section
